# API

SMLMData defines only the two entries below. Every name it exports is documented where it is
defined: the types and operations in the
[SMLMCore API](https://JuliaSMLM.github.io/SMLMCore.jl/stable/api/), the SMITE functions in the
[SMLMio API](https://JuliaSMLM.github.io/SMLMio.jl/stable/api/). In the REPL, `?name` shows the
same docstring for either spelling (`?BasicSMLD`, `?SMLMData.BasicSMLD`).
